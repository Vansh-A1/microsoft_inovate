# CL-08 independent public invoice evaluation

Four externally authored **fictional** sources; no new invoices were generated by
this project. All 19 item rows and selected header facts were checked directly
from original PNG pixels or every rendered original PDF page **before inference**.
The authors' expected JSON, extraction services and generation programs were not
fetched or executed. Production code remains exactly the measured 0319cf4 version.

Both authors explicitly mark these samples synthetic; inspected sources contain
fictional/example business details. No real customer invoice, personal account,
restricted dataset, token/signup or new service was used. Anonymous GitHub API
metadata was rate-limited; anonymous `git ls-remote` and pinned public raw files
provided provenance without credentials. License/README notices were fetched and
checked before selected PDFs/PNGs were downloaded. No remote code was installed.

Original files, license/README download receipts, source renderings and full API
outputs stay under ignored `runtime/clearledger/public-research` / `runtime/clearledger`.
The source bytes/hashes and pipeline/truth hashes are immutable. The new evaluation
script expects those authorized locally cached originals and never downloads them,
injects truth, trains, corrects an invoice or submits finance transactions:

```bash
.venv/bin/python scripts/benchmark/clearledger_public.py --label a-new-label
```

Existing result labels cannot overwrite previous evidence. `manifest.json` was
frozen before this actual evaluation. Header/row text checks preserve grouping and
decimal punctuation; only independently printed currency tokens/whitespace may be
removed for money comparison. Explicit p01 name/description checks cover English
segments only, not Arabic accuracy. All missing/wrong-page/unassigned rows remain
in the denominator. `$` does not establish USD; canonical abstention is separate
from literal success. Money/date/currency normalization and complete accounting
are separate from readable source facts and finance clearance.

**Erratum:** p01's frozen layout label incorrectly says "native". Its original PDF
has **zero native characters** and follows OCR→VLM. This source-type correction is
recorded alongside the unchanged manifest, truths and scores. p03/p04 have native
text; p02 is a PNG. No score/expectation was changed after observing output.
